# Tutorials

These tutorials build on [Get started](../getting-started/index.md). Follow them
in order for an end-to-end path, or choose the task you need.

1. [Transform a model](transform.md) — compose functions, query state, and
   record execution evidence.
2. [Write a mod](write-mod.md) — add an out-of-tree package without changing
   the compiler core.
3. [Import ONNX](import-onnx.md) — decode source operations and convert
   semantics explicitly.
4. [Emit C](emit-c.md) — prepare a checked graph, plan storage, emit strict
   C11, and run a harness.

Each page names the maintained tests that cover its workflow. Tutorial code is
not a second implementation.
