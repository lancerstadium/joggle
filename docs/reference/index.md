# Reference

Reference pages answer exact API and syntax questions. They assume you already
understand the workflow in [Get started](../getting-started/index.md).

- [Language reference](language.md) — lexical rules, declarations, types,
  expressions, control flow, generics, handles, and metadata.
- [Mod catalogue](module-catalogue.md) — installed package responsibilities
  and public operations.

Use `joggle --help`, `joggle COMMAND --help`, and
`joggle mod info NAME -M build/modules` for the authoritative surface of the
binary on disk.
