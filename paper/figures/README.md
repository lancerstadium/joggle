# Paper figures

Only submission candidates rendered from frozen records belong here. The old
three-panel extension-source bar chart was removed: it was sparse, emphasized
line counts over mechanisms, and could not represent unsupported endpoints
without a second visual grammar.

The replacement is specified in [`../figure-plan.md`](../figure-plan.md): a
wide Motivation boundary map, aligned whole-model small multiples, and native
LaTeX speedup matrices. No placeholder figure is checked in before its complete
record set exists.
