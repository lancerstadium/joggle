\subsection{Recorded Agent Code and Diagnostic}
\label{sec:agent-code}

The \texttt{ana-numeric-range} contract asks: ``Propagate closed finite real
intervals through add, multiply, ReLU, and clamp using endpoint arithmetic;
multiplication evaluates all four endpoint products.'' In the recorded
Qwen3-8B/Joggle trajectory, the final generated candidate was:

\begin{lstlisting}
mod extension
use base
use ir

fn analyze(m: Mod) -> dict {
  let subject = ir.find(m, "subject")
  let calls = ir.ops(subject, ["call"])
  let op = calls[0]
  let value = ir.outs(op)[0]
  let type = ir.type(value)
  let dimensions = args(type)[1]
  let element_type = args(type)[0]
  let interval = base.interval(element_type, dimensions)
  let mut result: dict = {}
  result["interval"] = interval
  return result
}
\end{lstlisting}

The compiler returned \texttt{module.jog:14:11: error: expected '='} with empty stdout.
The unmodified candidate exhausted 30 actions after 15 edits and 2,189 generated
tokens. \texttt{let mut} is invalid; mutable bindings use \texttt{var}. Separately,
the reference produces \texttt{\{"interval": [-12.0, 15.0]\}}
for $[-2,3]\times[-4,5]$.
